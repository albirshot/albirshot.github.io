# Alexey Biryukov — portfolio

Статический сайт на HTML, CSS и JavaScript. Без npm, сборки и платных сервисов.

## Открыть локально

Для видео нужен интернет. Для корректной работы YouTube и Vimeo запустите в этой папке `python3 -m http.server 8080` и откройте http://localhost:8080.

## Содержимое

- `index.html` — галерея WORK и YouTube/Vimeo-плеер.
- `about.html` — знакомство, портрет и контакты; `contact.html` сохраняет доступ по прежней ссылке.
- `styles.css` — адаптивный дизайн и hover-эффекты.
- `script.js` — YouTube/Vimeo-плеер в диалоге.
- `assets/` — обложки из официальных YouTube/Vimeo oEmbed. Видео не скачиваются и не хранятся в проекте.

Плеер открывается по нажатию на превью, закрывается кнопкой CLOSE, Escape или нажатием вне диалога. При закрытии воспроизведение останавливается. Без JavaScript превью открывает видео на YouTube или Vimeo.

## Редактирование

Для новой работы скопируйте блок `<article class="project">` внутри `.project-grid`, укажите обложку, прямую ссылку и атрибуты `data-provider` (`youtube` или `vimeo`), `data-film` (ID видео), `data-title`, `data-year`, `data-duration`. Обновите подпись и `aria-label`. Плеер автоматически откроет выбранную работу. На desktop — три видео в ряд, на планшете — два, на телефоне — одно; новые карточки автоматически переходят на следующую строку.

## Резервный плеер RUTUBE — 25 октября 2026

У девяти сопоставленных работ над плеером доступны кнопки YouTube и RUTUBE. По умолчанию открывается YouTube. Переключение запускает видео заново и удаляет предыдущий iframe, останавливая его звук. Обложки и порядок карточек не менялись. Две существующие работы Vimeo сохраняют свой исходный плеер.

Резервная ссылка задаётся атрибутом `data-rutube` на карточке: полная ссылка `https://rutube.ru/video/private/ID/?p=КЛЮЧ`. Ключ `p` обязателен для видео по ссылке и сохраняется во встроенном плеере. Без подтверждённой резервной ссылки переключатель скрыт. Прямая ссылка под видео меняется вместе с выбранным сервисом.

Инструкция RUTUBE: https://rutube.ru/info/embed/

В родительской папке `rutube-links.json` хранит все 19 предоставленных ссылок и результаты сопоставления; `RUTUBE-status.md` — список работ, пока не имеющих подключённой копии. Не назначайте недоступные ролики карточкам по порядку: сначала нужно проверить их названия после модерации.

## Новый дизайн — 27 октября 2026

Крупный первый экран с беззвучными фрагментами трёх работ: «ЕТП Балерина» (105 с), «17 мгновений весны» (15 с), «Китайский Новый год» (4 с). Каждый фрагмент длится до 13 секунд. Видео поступает через YouTube embed; локально хранятся только обложки. При недоступности видео остаётся смена обложек. Есть пауза и ручной выбор сцены; при reduced motion фон не запускается автоматически.

Меню: ABOUT, WORK, INSTA, TELEGRAM, EMAIL. Кнопка F/24 соответствует тёмной теме, F/1.4 — светлой. Выбор сохраняется между страницами. `theme.js` применяет его до загрузки оформления.

Заголовки используют бесплатный Cormorant Garamond Regular с кириллицей. Шрифт находится в `assets/cormorant-garamond-regular.ttf`, лицензия SIL OFL — в `assets/Cormorant-OFL.txt`. На странице About размещены портрет, русский текст и компактные контакты. Все 22 работы, порядок обложек и 20 резервных плееров сохранены.
